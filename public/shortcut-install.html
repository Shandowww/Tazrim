חזרה ל־Budgit

התקנת קיצור Apple Pay

דף ההתקנה נפתח בנפרד. אפשר לחזור ללשונית או לאפליקציית Budgit המקורית בלי לאבד את מסך החיבור.

הורדת האוטומציה ל־iOS 27

פתחו את הקובץ בהורדות Safari או בקבצים. ההוספה נפתחת באפליקציית קיצורים של Apple.

  1. הדביקו את מפתח החיבור שהעתקתם מ־Budgit. אין לשלוח אותו בצ׳אט.
  2. הגדירו את המטבע. בחרו בטריגר Wallet רק את הכרטיס המתאים למפתח, ואז הפעילו Automation.
  3. כבו אוטומציה ישנה לאותו כרטיס כדי למנוע שליחה כפולה.
  4. חזרו ל־Budgit דרך הלשונית המקורית או הכפתור למעלה. אחרי רכישה אמיתית בדקו את הייבוא.

הגרסה המשולבת משתמשת במטבע קבוע. לכרטיס עם עסקאות במטבעות שונים השתמשו בגרסה הידנית.
