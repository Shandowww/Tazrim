# Simplified workspaces — review preview, 2026-11-11

Tal approved continuing the menu audit recommendations. This stage keeps the accepted adaptive layout, original theme and currency repair. Production promotion still requires explicit approval of the reviewed design.

## Navigation

The six financial workspaces remain. There are now 9 secondary entries instead of 22 (17 total destinations including the six workspace entrances and Settings/Help, previously 30). Setup and record actions are no longer a permanent submenu inventory.

| Workspace | Regular views | Contextual capabilities |
| --- | --- | --- |
| Accounts | Banks/cards; transfers | Existing per-card edit and account actions; paying-account assignment under account settings; cross-space overview beside the space selector when multiple spaces exist; migration in an account's advanced settings |
| Reports | Inbox; sources/upload; import history | Original sync source settings and expected dates; notices and manual entry under report settings; alerts in the existing bell |
| Expenses | Categories/details; comparisons; recurring patterns | Search on the category page; category naming/colours and limits in contextual management; manual detail list excludes cheques when entered from Expenses |
| Planning | Purchases/payments; income; loans; cheques | Affordability calculator beside planned items; forecast defaults and monthly targets in planning settings |
| Savings | Goals/balances; deposits | Existing-balance update, allocation, redistribution and growth calculator beside goals; one-off and monthly deposit planning together in Deposits |

Settings contains Account & sharing, Privacy & recovery, and Connections. Appearance is immediate as before; interface/layout overrides are collapsed under advanced display settings. Server administration appears only after the existing identity-validated actions API reports server-admin capability. Wallet maintenance appears only for an active existing connection, based on the original identity-validated Wallet read. Unavailable capability checks have an explicit retry; results are scoped and aborted on navigation. Guided setup is reachable from Help.

## Boundaries

All original routes, commands, save conventions, draft guards, role checks and financial meanings remain. Navigation does not make a financial save. The manual-detail filter is presentation only; existing cheque views and records are retained. Deposit planning does not execute a bank transfer or mark a planned amount as completed. No financial model, database schema, server permissions or production records change.
