# Report coverage across accounts on desktop

Tal requested showing all account/card report coverage immediately on the web, using the available space instead of selecting one entity from a dropdown.

At widths of 1024px and above, the existing “What is missing” screen uses the available content width and displays every bank/card row, with six aligned month cells and an explicit bank/card label. The entity selector is hidden. At narrower widths, the existing selector and selected row remain. Changing screen width preserves the selected entity, period and scope.

Every cell continues to open the original account/card/month detail through the existing guarded route. Returning restores the full desktop map. Coverage states, expected dates, missing-report counts, financial commands, access checks and phone interactions are unchanged. This is presentation only, in the isolated sample-data preview; production requires approval of the reviewed design.

Verification and hosted results are recorded in the accompanying evidence receipt. No new physical-iPhone acceptance is claimed.
