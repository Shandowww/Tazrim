Digest = extract + reconcile + prepare a proposed update. Applying that update to the budget is a separate operation. Phase 2 review happens before financial records change. The UI label “Digested” means fully handled and saved, not merely prepared.

1

Verify before digestion

Files arrive automatically. You decide when Budgit may analyze each one.

  1. Save to your folderOne folder per user
  2. Automatic uploadOriginal stored; receipt checked
  3. Verify the reportYou confirm the exact file
  4. Read + match accountAccount number / issuer + card digits
  5. Review and saveExisting financial approval
  6. Budget updatedOnly approved changes

Gate: no extraction, classification or issuer-notice analysis before verification.

2

Review prepared changes

Budgit prepares the report. Clear separate screens guide your review; Finish saves the result.

  1. Save to your folderSame per-user setup
  2. Automatic uploadSafe duplicate handling
  3. Automatic digestionKnown account and period
  4. Guided reviewAccount → figures → categories → exceptions
  5. Summary + FinishNext preserves progress; Finish approves saving
  6. Budget updatedRevision and access rechecked

Gate: preparation is automatic; financial application still waits for you.

3

Full automatic processing

Eligible reports update Budgit. You handle exceptions and review results.

  1. Save to your folderSame per-user setup
  2. Automatic uploadReceipt and retry protection
  3. Automatic digestionOnly enabled source families
  4. Eligibility checksIdentity, totals, conflicts, access
  5. Automatic applicationAudit record and safe correction
  6. Result summaryOrdinary successes grouped

Exception branch: only exceptions open the guided decision screens; eligible reports need no Next/Finish interaction.
